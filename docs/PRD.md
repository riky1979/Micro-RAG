# PRD: Micro-RAG

## 목표
소규모 모임·소상공인이 가진 '극도로 사적인 실시간 데이터'(회비·일정·재고 등)를 한 줄 메시지로 AI에 학습시키고, 멤버 누구나 자연어로 조회한다.

## 사용자
- **운영진** — 공지·영수증·일정 변경을 주입 콘솔에 텍스트로 입력
- **멤버** — 등록된 우리 모임 정보를 질문 페이지에서 자연어로 조회
- 동호회, 스터디, 소상공인 등 10~50명 규모 모임

## 핵심 기능
1. **팀 생성** — slug 기반 네임스페이스 (`/[team]`)
2. **데이터 주입** — 비정형 한국어 텍스트를 Claude가 구조화 레코드(category·title·summary·entities·effective_date)로 변환하고, 검색용 텍스트를 임베딩해 함께 저장
3. **질의응답** — 질문을 임베딩해 팀 범위 벡터 검색 후, Claude가 등록된 정보만 근거로 답변

## MVP 제외 사항
- 사용자 인증·권한 — slug를 알면 누구나 접근 (의도된 범위)
- 문서 수정·삭제 — 주입과 조회만 지원
- 파일·이미지 업로드 — 텍스트 전용
- 한국어 외 다국어 지원

## 디자인
- 라이트 모드 고정 — 오프화이트 배경 + 웜 오렌지 포인트 1가지
- 도구형 미니멀 UI — 매일 쓰는 대시보드 느낌, 마케팅 페이지 지양
- AI 슬롭 안티패턴 회피 (`docs/UI_GUIDE.md` 참조)
